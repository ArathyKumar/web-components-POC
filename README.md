# Web Components POC

A proof of concept for building and sharing reusable web components.

## Overview

This project explores native [Web Components](https://developer.mozilla.org/en-US/docs/Web/API/Web_components) — custom elements, shadow DOM, and HTML templates — as a way to create encapsulated, framework-agnostic UI building blocks.

## Getting Started

```bash
# Install dependencies (once package.json is added)
npm install

# Start development server (once scripts are configured)
npm run dev
```
