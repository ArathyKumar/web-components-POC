Card

PatternFly card examples mirror the PatternFly Card, implemented as <pf-card-shadow> and <pf-card-light>. The shadow variant uses encapsulated CSS, native named <slot> elements for content projection, and exposes ::part() selectors for targeted external theming. The light variant renders its BEM structure directly into the document, inherits global patternfly.css without adoption, and uses data-card-slot wrapper divs to manually re-project slot="..." children on every render cycle — because light DOM has no native slot mechanism.

Theming

Shadow DOM is themed via pf-card-shadow::part(card) { border-left: 4px solid var(--pf-t--color--blue--60); }. Light DOM is themed via pf-card-light .pf-v6-c-card { border-left: 4px solid var(--pf-t--color--blue--60); }.

Themed via ::part(card)

External CSS can only reach shadow internals through ::part(card). Without the part attribute, this element is unreachable from the outside.

Themed via BEM class selector

External CSS targets .pf-v6-c-card directly because there is no shadow boundary. No ::part() needed — but the internals are also fully exposed to global CSS.
