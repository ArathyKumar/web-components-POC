Badge

PatternFly badge examples mirror the PatternFly Badge, implemented as <pf-badge-shadow> and <pf-badge-light>. The shadow variant uses an encapsulated stylesheet, native <slot> for content projection, and exposes ::part(badge) for theming. The light variant relies on global patternfly.css, uses a count attribute instead of a slot (native slots require a shadow root), and is themed via standard BEM selectors.
